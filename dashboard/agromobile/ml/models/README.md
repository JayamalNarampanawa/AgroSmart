# ML Model Artifacts

This folder stores both local ML backends used by the mobile app.

## Sales Forecasting Artifacts

Primary deep learning artifacts:

- `sales_lstm.keras`
- `sales_lstm_metadata.json`
- `sales_history.csv`

Legacy baseline artifacts:

- `tuned_model.pkl`
- `preprocessor.pkl`
- `model_metadata.json`

Generated by:

```powershell
python ml\training\train_sales_lstm.py
python ml\training\train_sales_model.py
```

## Crop Prediction Artifacts

Primary deep learning artifacts:

- `crop_mlp.keras`
- `crop_mlp_metadata.json`

Generated by:

```powershell
python ml\training\train_crop_mlp.py
```

## Runtime Services

- `ml/api/main.py` serves sales forecasting on port `8001`
- `ml/crop_api/main.py` serves crop prediction on port `8766`
